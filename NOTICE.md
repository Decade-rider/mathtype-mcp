# Source provenance

The Office STA worker, private Word workspace, native range transfer, font-metric
reader, validation, document management, and parts of the layout/numbering framework
were adapted from the AxMath MCP project in November 2026. Corresponding tests were
adapted where applicable. MathType MCP is an independent copy, with no runtime
dependency on an AxMath MCP checkout.

The upstream repository URL and licensing disposition have not been specified by
the maintainer. This notice records provenance; it does not assert a license grant.
