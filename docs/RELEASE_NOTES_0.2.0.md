# MathType MCP v0.2.0 — Alpha

Windows 桌面 Word 的独立 MathType MCP：原生可编辑公式插入、读取、修改，以及 MathType 原生连续编号。

- 12 个 MCP 工具，支持 inline / display / numbered。
- 新增已有公式补号与编号刷新；更新公式保留原编号。
- 输入检查、文档 ID 定位、临时转换隔离与显式保存。
- 提供 uv 安装流程、Codex 注册脚本、通用配置和本机验收脚本。

需要自行安装可正常使用的 Word 和 MathType。本版本不包含厂商软件，也不提供授权。许可证状态待确认，参见 LICENSE_STATUS.md。

已完成本机测试，但尚未覆盖全部 Office/MathType 版本。PowerPoint、自定义内部字号、章节格式配置与交叉引用刷新暂不支持。外部客户端中曾出现的 Word 工作文件弹窗尚未确认根因；详见排错说明。
